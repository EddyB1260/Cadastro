Cadastro de Usuários

Sistema de cadastro de usuários desenvolvido com React, Django REST Framework e PostgreSQL.

📋 Sobre o projeto

Este projeto foi criado com o objetivo de estudar o desenvolvimento de aplicações full stack utilizando:

React + Vite no frontend
Django REST Framework no backend
PostgreSQL como banco de dados
API REST para comunicação entre frontend e backend
ORM do Django para persistência de dados

Atualmente a aplicação permite:

✅ Criar usuários
✅ Listar usuários
✅ Buscar usuário por ID
✅ Atualizar usuários
✅ Excluir usuários
✅ Consumir API REST através do React
